# 🚀 Jenkins + GitHub + Maven + Tomcat Integration

This project demonstrates a **Continuous Integration (CI) and Continuous Deployment (CD) pipeline** using Jenkins, GitHub, Maven, and Tomcat. The pipeline automates the build and deployment process, ensuring that any changes made in the GitHub repository are automatically built into a `.war` file and deployed on an **Apache Tomcat** web server running on **AWS EC2**.

---

## 📌 Project Overview  
✅ **Automated Build & Deployment:** Automatically packages and deploys a Java web application.  
✅ **Jenkins + GitHub Integration:** Triggers builds when changes are pushed to the repository.  
✅ **Maven for Build Management:** Uses Maven to package the application into a `.war` file.  
✅ **Tomcat Web Server:** Deploys the `.war` file on a Tomcat server running on **port 9090**.  
✅ **AWS EC2 Hosting:** Runs both Jenkins (port 8080) and Tomcat (port 9090) on an EC2 instance.
